## Vérification gratuite
`npm run build` génère public-build/INTEGRITY.json avec SHA-256 et taille des fichiers réellement distribués, hors manifeste lui-même. `npm run integrity:verify` vérifie le contenu exact et détecte aussi les fichiers ajoutés ou absents. Archiver le manifeste avec le SHA Git et le résultat CI. Ce n'est pas un horodatage qualifié, une signature numérique, une protection anti-copie ou un dépôt officiel. Les licences et autorisations restent à vérifier au besoin. Aucun dépôt payant engagé.
