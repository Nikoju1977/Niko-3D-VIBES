## V4, module expérimental
- niko-gesture.js : nouveau code rédigé pour cette intervention avec assistance IA, à partir de géométrie vectorielle générale et de filtrage exponentiel adaptatif. Aucun fichier des trois dépôts sources n'a été copié pour ce module. Le code historique a été consulté pour l'interface de compatibilité, donc il ne s'agit pas d'une réimplémentation clean-room certifiée.
- niko-gesture.test.js : tests originaux sur repères synthétiques, sans données personnelles.
- neuro.js, app.js : intégration au code existant, sans retirer les mentions de provenance.
- Les modèles MediaPipe restent des dépendances tierces et ne sont pas des modèles Studio Niko.

La politique LICENSE.md reste inchangée. Les éventuels droits sur les contributions nouvelles sont réservés dans la mesure où ils existent effectivement. Les droits MIT préexistants demeurent intacts. Pas de revendication d'invention brevetée ni de paternité exclusive sur les méthodes mathématiques générales. Une analyse indépendante est nécessaire avant une revendication juridique de réimplémentation intégrale.

- niko-spatial.js : nouveau module de rendu WebGL2, géométrie procédurale historique réutilisée; aucune prétention de réimplémentation intégrale indépendante.

- niko-avatar.js : nouveau module de retargeting directionnel et quaternion à partir de géométrie générale; repères MediaPipe tiers, aucun nouveau modèle IA propriétaire.

- niko-motion-studio.js : nouveau module de morphologie et export GLB, géométrie cylindrique procédurale, assistance IA; licences et notices antérieures conservées.

- V5 niko-native.js : nouveau calcul d'angle par atan2, cadence par alternance de flexion bilatérale, assistance IA. Ancien engine.js conservé pour comparaison et provenance, exclu du build. Les conventions MediaPipe et commandes virtuelles compatibles restent en usage. Pas de certification clean-room ni modification de licence.
